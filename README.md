<h1>Moon Space Rover</h1>

<h2>Project Idea</h2>
The idea of this project is to help NASA create a rover to find water on the moon, this could be beneficial as it is beneficial to sustain human life and and to manufacture rocket fuel for deep space exploration.

<h2>Technology/Tools</h2>
For this we will need to create a body. Attached to this body will be a way to move around, could be wheels, treads, or legs. We will need a computer to act as a brain to this robot, we can attach navigation cameras, sensors to detect humidity and water levels. Attach hands to the main body to allow the rover to interact with the terrain. Finally, we can have a power source such as rechargeable batteries and solar panels.

<h2>How to Use The Project</h2>
<h2>Step 1</h2>
Firstly we create a a simple design of our rover, we decide the size, shape, and where each part will go.
<h2>Step 2</h2>
We build the rover's main body using strong, lightweight material. We attach 4 wheels with small electric motors to allow the rover to move around.
<h2>Step 3</h2>
Attach rechargeable batteries and solar panels to provide and store electricity for the rover.
<h2>Step 4</h2>
Install a camera, water detecting sensors and an antenna to collect and send information to Earth. 
<h2>Step 5</h2>
Install a small computer and program it to control the wheels, camera and sensors.
<h2>Step 6</h2>
Test the rover on Earth to ensure everything works fine before sending it to space.
